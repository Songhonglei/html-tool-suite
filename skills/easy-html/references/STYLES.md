# 19 种内置样式速查

样式由 [html-golive](https://github.com/Songhonglei/html-golive) 提供，easy-html 通过 `scripts/apply_style.py --style <key>` 应用。
CSS 只管「皮肤」（配色/字体/边框/阴影），不动布局；靠 `data-role` 属性匹配元素。

## 特色字体（部分主题有性格字体，选样式时可据此推荐）

多数主题用 Inter（通用现代），有性格的主题配了专属字体，气质差异明显：

| 主题 | 字体 | 气质 |
|------|------|------|
| `newspaper` | Playfair Display | 杂志衬线，编辑感 |
| `ink` | Noto Serif SC / ZCOOL QingKe HuangYou | 中式书法，水墨味 |
| `palace` | 标题 Ma Shan Zheng（毛笔行楷）+ 正文 ZCOOL XiaoWei（站酷小薇·古风衬线）| 故宫古色古香，标题正文统一古典 |
| `steampunk` | Cinzel | 复古罗马衬线 |
| `cyberpunk` | Rajdhani | 科技几何感 |
| `bloomberg` | IBM Plex Mono | 金融等宽，终端感 |
| 其余 | Inter | 通用现代无衬线 |

> 字体走 fonts.font.im 公网 CDN；中文字体（Noto Serif SC / Ma Shan Zheng）文件较大，
> 首屏可能略慢但能加载。需要字体特色时优先推这几个主题。

## 给用户选样式时的话术

列出 19 种 + 按内容智能推荐 1-2 种，让用户选。例如内容是财务复盘：

> 我建议用 **Bloomberg 终端风**（深色金融数据感）或 **极简优雅风**（通用清爽）。
> 也可以从这 19 种里挑：Apple 质感 / Cowork 轻科技 / 赛博科技 / 水墨卷轴 /
> 报纸杂志 / 故宫风 / 蒸汽朋克 / 小红书简洁 / 小红书丰富。你想要哪种？

## glass（玻璃拟态）注意

`glass` 的背景是**彩色渐变**（铺在 body 上），卡片半透明磨砂浮在其上，依赖
`backdrop-filter`（现代浏览器均支持）。骨架同样只带语义结构即可，配色/磨砂全交给皮肤。

## 深色样式注意

`bloomberg` / `palace` / `steampunk` / `cyberpunk` / `carbon` 是深色背景
（`carbon` 是低调炭灰开发者风，其余偏张扬）。
生成 HTML 骨架时**不要写死浅色背景/深色文字**，否则会和深色皮肤冲突 ——
让元素只带语义结构（见 DATA_ROLE.md），配色完全交给样式 CSS。
