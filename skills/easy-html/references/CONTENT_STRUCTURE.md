# 内容类型 → 版式映射 + 内容质量原则

决定生成什么 HTML「骨架结构」。皮肤由样式 CSS 决定，这里只管结构和内容呈现。
（移植自 xhs-viz-page 的内容侧规范，去掉了固定配色/900px 等视觉皮肤约束。）

## 内容类型 → 推荐骨架

| 内容类型 | 推荐结构 |
|---------|---------|
| 月报 / 周报 | hero 标题 + 核心数据看板(stat-block) + 分维度 section + 案例卡片 + 总结建议 |
| 数据复盘 | 问题陈述 + 数据对比(data-table/图) + 原因分析 + 行动建议(callout) |
| 客户分析 | 客户概览 + 分层分布 + 重点客户卡片(card-grid) + 风险预警(callout) |
| 行业规划 / 策略 | 背景 + 目标 + 策略模块(section) + 时间轴(timeline) + 资源配置 |
| 投放分析 | 场域分布 + 目的拆解 + 广告主排名(data-table) + 趋势图 |
| 项目结项报告 | 项目概览 + 目标达成(progress-bar) + 推进节奏(timeline) + 复盘 + 未来方向 |
| 通用文档/纯文字 | hero 标题 + 按原文层级拆 section + 表格转 data-table + 重点转 callout |

## 图表选择（按需，不设禁区）

核心原则：**图表服务于内容，选最能说明问题的**。可按需使用任意图表类型
（包括饼图、3D 图表），由数据特征和表达需要决定。

| 数据场景 | 可选图表 |
|---------|---------|
| 占比 / 构成 | 环形图、饼图、半圆仪表盘、马赛克图 |
| 趋势变化 | 面积图、折线图、阶梯图 |
| 对比排名 | 水平条形图、棒棒糖图、子弹图 |
| 多维对比 | 雷达图、热力矩阵 |
| 流程 / 漏斗 | 渐变漏斗、桑基图 |
| 单个大数字 | 数字卡片 + 同比箭头 + 迷你火花线 |
| 分布密度 | 气泡图、散点图 |
| 进度达成 | 进度条、环形进度 |
| 关键词 / 标签 | 标签云 |

**实现方式**：优先纯 CSS + SVG 手写；复杂图表引入 Chart.js（CDN，需多源兜底，
单一 CDN 偶发不可达）。同页图表类型不宜过多（一般 ≤5 种，保持可读）。

## 内容质量原则（必须遵守）

- **0 遗漏**：原始材料中所有数据、文字、案例必须完整呈现，不得概括删减。
- **数据准确**：百分比、绝对值、增长率严格区分，不混淆。
- **层级清晰**：主次分明，重要数据放大（stat-value），辅助信息缩小。
- **中文优先**：标签、说明用中文，专业术语保留原文。
- **图片处理**：原文含图片时，优先用 CSS/SVG 把数据重新可视化；
  确需保留原图，用可访问 URL（本地图先传到任意图床/对象存储）。

## 字体/CDN 注意

- 样式 CSS 自带字体引用（fonts.font.im 镜像），无需额外引入。
- 若用 Chart.js 等外部 CDN，配 3-4 个 fallback 源 + 超时降级（单源偶发不可达）。
